# ねるトレ ― 制作判断メモ

> アプリ名：ねるトレ（今日の自分を、5分で。）

## 1. 何を記録するアプリか

仕事に追われて、「今日、自分は何をしたんだろう」と思いながら眠る人のための、寝る前5分の日記アプリです。

その日の出来事だけでなく、次の4つを記録します。
- **気分**：その日の気分を、-2（かなり沈んでいる）〜 +2（かなり良い）の点数で残します。
- **心の声**：「ちゃんと進めてるか」のように、自分を急かしたり責めたりする言葉です。
- **気分が戻ったきっかけ**：ジムに行った、人と話した、などです。
- **答えの出ていない問い**：サンプル日記の6/3でいえば、「これって成長してるのか、ただ回してるだけなのか分からなくなる」です。

日記が続かない理由の一つは、続けても変化が見えないことです。

そこで、書いた言葉が後の日の言葉とつながっていく様子を見せて、「続けてよかった」と感じてもらうことを目的にしました。

## 2. まとめプロンプトの狙い

プロンプトは、AIへの指示書です。指示を書くときに、次の4つを大事にしました。

### 狙い1：数字や日付は、AIに任せない

AIは文章を読むのは得意ですが、平均の計算や日付の扱いを間違えることがあります。

そこで、気分の平均などの数字はアプリ自身が計算し、AIには「この数字は書き換えないこと」と指示しました。AIの役割は、数字を本人に届く言葉にすることだけです。

また、「あった日」と「なかった日」を比べるのは、それぞれ2日以上ある場合だけにしました。1日だけで比べると、たまたまの差が大きく見えてしまうからです。

### 狙い2：本人の言葉を、そのまま使う

「」で囲むのは、本人が書いた文そのままのときだけ、とすべての指示に書きました。さらにアプリが、AIの引用を日記の原文と照らし合わせて、一字一句そろえています。

本人が書いていない言葉を「あなたの言葉」として見せると、振り返り全体が信用されなくなるからです。

### 狙い3：前の悩みへの「答え探し」は、別の指示に分ける

最初は、1週間の振り返りを書く指示の中で、答え探しも一緒に頼んでいました。すると、6/3の悩みと、6/5の「自分の経験がそのまま役に立って」という一文がつながりませんでした。

そこで答え探しだけを別の指示にし、次の順番で考えてもらうようにしました。

## 1. 悩みの奥にある不安を、一文で言葉にする

## 2. その不安を揺さぶる出来事を、後の日の日記から探す

## 3. 悩みと同じ場面の出来事だけを、「答え」として扱う

3つ目は、休みの日の焦りに、仕事で褒められた話を無理に当てはめないためのルールです。

### 狙い4：診断も、助言もしない

AIには「評価も助言もしない、静かな聞き役」に徹するよう指示し、心の診断や性格の決めつけを禁止しました。深刻な内容のときは、まとめるのをやめて、短くねぎらうよう指示しています。

相談窓口の名前と電話番号は、AIに書かせず、アプリに直接書きました。自分を傷つけることをうかがわせる言葉はアプリ自身も確認し、AIの返事を待たずに相談窓口を表示します。

## 3. UXで意識した点（使いやすさの工夫）
- **寝る前に、頭を使わせない。**書くのは1日1回で、AIとの会話は続けません。返事は短くし、明日の課題やアドバイスは出しません。
- **何を書けばいいか迷わせない。**入力欄の上に「今夜の問い」を1つだけ出します。前回の日記や、答えの出ていない悩みから作るので、続けてきたことが次の夜につながります。
- **夜遅いときは、もっと軽く。**23時30分を過ぎたら「一言でも大丈夫です」と添えます。深夜0時から朝5時前までに書いた日記は、前の日の夜の分として保存します。
- **話すだけでも記録できる。**マイクで話した言葉を文字にします。読み上げは、ボタンを押したときだけにしました。
- **待ち時間を「読んでもらっている時間」に。**AIが読んでいる間、本人の文章が一文ずつ灯ります。まとめができたら、拾った言葉を光らせてから結果を見せます。
- **振り返りは3枚のカードに。**振り返りで知りたい「何に気づいたか・どんな傾向があるか・何が変わったか」に合わせて、「気づき・傾向・変化」の3枚にしました。各カードには一文と根拠を1つだけ見せ、詳しい説明は「くわしく」を開いた人だけが読めます。
- **数字の意味を、その場で分かるように。**「あった日 +1.5」のような数字の下に、「数字は、その日の気分（-2〜+2）の平均です」と一行添えました。
- **書き忘れても、まとめて貼っても大丈夫。**1行目に「6/8（日）」と日付を書けば、その日の分になります。何日分かをまとめて貼ることもでき、サンプル日記もそのまま読み込めます。
- **画面は2つだけ。**「今夜」と「1週間」の2つのタブだけで、設定画面は作りませんでした。AIを使うための鍵（APIキー）は、最初に一度入力するだけです。

## 4. このアプリならではの工夫

### 前に書いた悩みの「答え」を、後の日の日記から見つける

いちばんの見せ場です。本人が気づかないうちに、前に書いた悩みへの答えを、後の日に書いていることがあります。

例：6/3に「ただ回してるだけなのか分からなくなる」と書いた悩みに、6/5の「自分の経験がそのまま役に立って、『ありがとうございます』と言われたのが素直に嬉しかった」が答えていた、と見せます。

答えが見つからない悩みは、無理に答えを作りません。6/7の「せっかくの休みを無駄にしてないか」は、「まだ預かっている問い」として残します。

### 本人の思い込みと、実際のずれを見せる

サンプル日記の本人は、「ジムだけは、ちゃんと積み上がってる実感がある」と書いています。

ところが気分の点数を比べると、人と関わった日のほうが、気分の差が大きく出ていました。

アプリが「〇〇だけは」という言葉を自動で見つけ、このずれをAIが一文にして見せます。

### 「積み上げ」で、筋トレのように手応えを残す

アプリ名の「ねるトレ」のとおり、記録を筋トレのように見せました。毎日のまとめに「今日の積み上げ」を残し、「『体を動かす』は先週2回。今週はこれで1回目」のように、先週と比べた回数も出します。変化が見えにくい毎日にも、小さな手応えが残ります。

### 田中さん以外の人でも、同じように使える

気分が戻ったきっかけは、「体を動かす」「人と話す」などの決まった分類から選ぶので、誰の日記でも同じように数えられます。1週間のグラフで強調する日も、その週にいちばん気分の差が大きかったものを、アプリが自動で選びます。

### 補足：AIの使い分け

すぐに返事がほしい「今夜の問い」と「1日分のまとめ」には、返事の速いAI（gpt-4.1）を使いました。何日も離れた言葉をつなぐ「答え探し」と「1週間の振り返り」には、時間をかけて深く読めるAI（gpt-5.4）を使っています。

AIへの指示の組み立てにはLangChain.jsを使い、AIの答えは決まった項目の形で返してもらうようにしました。
